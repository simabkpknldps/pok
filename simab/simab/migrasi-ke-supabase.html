🔄 Migrasi Firestore → Supabase

Ambil data dari Firestore (yang sudah kita migrasi sebelumnya), tulis ke tabel Supabase. Tiap kartu independen, urutan bebas.

⚠️ Pastikan RLS Supabase sudah dibuka sementara (jalankan supabase-rls-open-temp.sql dulu), dan kamu sudah login di SiMAB (buat akses Firestore).

1. Pegawai

Firestore koleksi 'pegawai' → tabel pegawai. Id = NIP.

2. Kegiatan

Firestore koleksi 'kegiatan' → tabel kegiatan. Id = id kegiatan (sama seperti Firestore).

3. POK

Firestore koleksi 'pok' → tabel pok. Id = Kode+Seksi (sama seperti Firestore).

4. Blokir

Firestore koleksi 'blokir' → tabel blokir. Id = Kode.

5. SBM Uang Harian

Firestore koleksi 'sbm' → tabel sbm. Id = nama Kabupaten/Kota.
