🧹 Hapus Field "password" dari Koleksi pegawai

Menghapus field password (plaintext, sisa migrasi awal) dari SEMUA dokumen di koleksi pegawai — tidak dipakai lagi karena login sekarang lewat Firebase Auth.

⚠️ Pastikan Security Rules Firestore SUDAH diubah sementara jadi: allow read, write: if request.auth != null; pada match /pegawai/{nip} (bukan yang self-only), dan kamu sudah login di SiMAB. Setelah proses ini selesai, KEMBALIKAN rules ke versi self-only lagi.
